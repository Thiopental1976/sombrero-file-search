# docs/historico/ — development diary

**These documents are in Portuguese, by design.** They are records of the moment — the
briefing that started the project, the handoffs and review requests exchanged while the work
happened, and the verdicts that closed each round. Translating them would rewrite history, so
they stay as they were written.

They are useful to understand **why** a decision was taken. For **how** the code works today,
read [`../TECHNICAL_DOCUMENTATION.md`](../TECHNICAL_DOCUMENTATION.md); where the two disagree,
the code wins (see §23 there).

| `HANDOFF_F9a_*`, `HANDOFF_F9_*` | Phase F9: the network-mount gate, `--index` (plocate), the copy engine |
