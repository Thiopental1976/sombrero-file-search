Sombrero File Search for Windows (beta)
=======================================

The Windows build is new and still being tested; Linux is the primary
platform. Windows 10 or 11, 64-bit. No installer, no administrator rights.

Install (once):

1. Right-click the .zip you downloaded -> Properties.
2. At the bottom, tick "Unblock" and click OK.
   (This avoids the blue "Windows protected your PC" screen.)
3. Right-click the .zip -> "Extract All..." -> pick a folder of yours,
   for example Documents.
4. Open the SombreroFileSearch folder and run SombreroFileSearch.exe.
   The first launch takes about a minute (Windows Defender scans the files);
   after that it opens right away.
   Tip: right-click SombreroFileSearch.exe -> "Show more options" ->
   "Send to" -> "Desktop (create shortcut)".

If the blue screen shows up anyway: click "More info", then "Run anyway".
The program is not signed with a paid certificate; that is why Windows warns.

Update: the program checks once a day and shows an update button at the top
right; you can also click the version number there -> "Check now". "Update"
downloads the new .zip to your Downloads folder. Close the program, delete
the old folder and extract the new one in the same place. Your settings and
saved searches are kept separately (%APPDATA%) and are not lost.

Problems and suggestions:
https://github.com/Thiopental1976/sombrero-file-search/issues
If the program closes on its own, attach the file
%LOCALAPPDATA%\Sombrero File Search\queda.log


Sombrero File Search para Windows (beta)
========================================

A versão para Windows é nova e ainda está em teste; o Linux é a plataforma
principal. Windows 10 ou 11, 64 bits. Sem instalador e sem administrador.

Instalar (uma vez só):

1. Clique com o botão direito no arquivo .zip que você baixou -> Propriedades.
2. Lá embaixo, marque a caixinha "Desbloquear" e clique em OK.
   (Isso evita a tela azul "O Windows protegeu o computador".)
3. Botão direito no .zip -> "Extrair Tudo..." -> escolha uma pasta sua,
   por exemplo Documentos.
4. Entre na pasta SombreroFileSearch e abra o SombreroFileSearch.exe.
   Na primeira vez ele demora quase um minuto (o antivírus do Windows confere
   os arquivos); depois abre na hora.
   Dica: botão direito no SombreroFileSearch.exe -> "Mostrar mais opções" ->
   "Enviar para" -> "Área de trabalho (criar atalho)".

Se a tela azul aparecer mesmo assim: clique em "Mais informações" e depois
em "Executar assim mesmo". O programa não tem assinatura digital paga; é
por isso que o Windows avisa.

Atualizar: o programa confere uma vez por dia e mostra um botão de
atualização no canto superior direito; você também pode clicar no número da
versão ali -> "Verificar agora". "Atualizar" baixa o .zip novo para a pasta
Downloads. Feche o programa, apague a pasta antiga e extraia a nova no mesmo
lugar. Suas configurações e buscas salvas ficam guardadas à parte (%APPDATA%)
e não se perdem.

Problemas e sugestões:
https://github.com/Thiopental1976/sombrero-file-search/issues
Se o programa fechar sozinho, anexe o arquivo
%LOCALAPPDATA%\Sombrero File Search\queda.log
