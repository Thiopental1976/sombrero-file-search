Ache todo arquivo. Saiba quando não deu.

O buscador de arquivos sem índice mais completo do Linux: por nome, por conteúdo, booleana e dentro de documentos, sempre ao vivo. Quando não conseguiu olhar em algum lugar, ela avisa.

Baixar AppImage última .deb para Debian / Ubuntu / Mint

Software livre, GPL-3.0-ou-posterior. O AppImage roda em qualquer distro, sem instalar nada. Versão para Windows em beta.

A tese

Busca que diz “0 resultados” sem ter olhado está mentindo.

Uma pasta que negou leitura, um disco que não estava montado, um NAS que parou de responder, um erro de digitação no caminho: cada um desses parecia exatamente com “o arquivo não existe”.

O Sombrero passa toda perda de completude por um canal único. A barra de status da interface, a CLI, o fluxo JSON e o código de saída leem dele, então um tipo novo de perda aparece em todos os lugares ao mesmo tempo.

$ sfs /mnt/backup -c fatura# incomplete: invalid location in /mnt/backup: path does not exist (disk unmounted? typo?)#        results are INCOMPLETE — this is not 'nothing was found'$ echo $?2
0achou
1olhou tudo e não achou nada
2o resultado pode estar errado: algum lugar não pôde ser buscado

A CLI fala inglês de propósito, para scripts do mundo todo; a interface gráfica segue o idioma do sistema.

Atenta aos discos, e medida

Uma cabeça mecânica, um processo.

Feito num servidor caseiro, e para ele: uma dúzia de discos mecânicos, discos SMR por USB e montagens de rede que às vezes morrem. As pastas são agrupadas pelo disco físico por trás delas, e cada tipo de disco recebe o número de threads que de fato aproveita. Todos os números foram medidos com cache frio.

1 094 s→80 s

A mesma busca num acervo de 10 montagens: um processo só com 24 threads, contra um processo por disco.

Recursos

Busca como o Agent Ransack, nativo do Linux.

Nome + conteúdo

Glob ou regex, texto simples ou regex, com destaque na prévia.

Booleana

(nota OR laudo) AND paciente NOT rascunho, com parênteses e frases entre aspas.

Dentro de documentos

PDF, docx, odt, epub e zip, pelo ripgrep-all embutido. Sem precisar de pandoc.

Prévia de mídia

Imagens e player de áudio e vídeo ao lado dos resultados: à direita numa janela larga, embaixo numa janela alta.

Buscas em sequência

Uma busca por aba. Cada disco passa para a busca seguinte assim que termina a anterior. Buscas salvas, histórico, exportação CSV/JSON.

Cópia segura

Nunca move nem apaga. Confere espaço livre, limites do FAT32 e nomes proibidos antes de gravar.

Duplicatas

Acha grupos idênticos byte a byte e nunca apaga. Qual cópia sai é decisão sua.

CLI equivalente

O mesmo motor. --print0 para pipelines, --json para scripts, --nice-io para o cron.

Localizador de duplicatas

Ache as cópias que estão comendo os seus discos.

Aponte para uma pasta ou para todos os discos. Ele devolve grupos de arquivos idênticos byte a byte, ordenados pelo espaço desperdiçado, mostrando em que disco fica cada cópia. Exporte a lista em CSV ou JSON e decida com calma.

Hard links são reconhecidos como o mesmo arquivo, e não como duplicatas: listá-los convidaria a apagar algo que não ocupa espaço extra.

  1. Mesmo arquivo?Os hard links são agrupados primeiro e contados uma vez só.
  2. Mesmo tamanho?Sai de graça: o tamanho já é conhecido. Tamanhos únicos saem da disputa.
  3. Mesmo começo?BLAKE2b dos primeiros 64 KiB elimina a maioria sem ler arquivos inteiros.
  4. Mesmo conteúdo.BLAKE2b completo só para quem sobrou, lendo um disco de cada vez para as cabeças mecânicas não brigarem.
Só leitura, por princípio

Ele busca. Não gerencia os seus arquivos.

O Sombrero não é um gerenciador de arquivos. Não tem botão de mover, renomear ou apagar, então nenhuma busca pode custar os seus dados.

Nunca move nem apaga

Não existe mover, renomear ou apagar em lugar nenhum do programa. As decisões sobre os seus arquivos ficam no seu gerenciador de arquivos, com você.

A cópia não toca no original

Copiar só cria arquivos novos. A origem nunca é alterada, e um arquivo que já existe no destino é pulado, a não ser que você escolha sobrescrever.

Duplicatas: mostra, nunca remove

Acha as cópias idênticas byte a byte e lista. Qual delas sai é decisão sua, tomada em outro lugar.

Instalar

Escolha o seu caminho.

AppImage qualquer distro

Nada a instalar. Python, PySide6, rg, fd e rga vêm embutidos.

chmod +x Sombrero_File_Search-*.AppImage
./Sombrero_File_Search-*.AppImage

.deb Debian · Ubuntu · Mint

Pacote enxuto. O --setup-gui monta o ambiente da interface na sua pasta pessoal.

sudo apt install ./sombrero-file-search_*_amd64.deb

Pelo código sem root

Instala em ~/.local. Funciona também em distros imutáveis.

git clone https://github.com/Thiopental1976/sombrero-file-search.git
cd sombrero-file-search && ./install.sh
